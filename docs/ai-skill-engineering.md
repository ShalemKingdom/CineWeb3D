Its two existing folders mirror each other; use .agents/skills/cineweb3d/SKILL.md in Codex from the repository root. Other compatible agents may read skills/cineweb3d/SKILL.md and its references alongside this repository. No global installation, hosted API, or autonomous deployment is provided.

Six routes: static, coffee-procedural, custom-procedural, glb, video, local-ai. It rejects invalid keys, paths, duplicate assets, commands and publication flags; unknown rights are excluded. It cannot certify business facts, actual file contents, licenses or authorization. It never executes a backend. No new dependencies.

Use in Codex: open the sandbox checkout, invoke $cineweb3d (or explicitly ask to read the skill if discovery is unavailable), describe the desired website, and ask to implement and verify. The skill directs the agent through the actual repository tools; do not claim the planner creates the site. Install/execute only approved tools.
