# Step 11 — SEO & Performance Shield

Sandbox only. No public site or search-engine submission. Both Vite and Astro now emit matching robots.txt/sitemap.xml and canonical/JSON-LD metadata for the root page. Indexing is opt-in, requires a syntactically valid HTTPS DNS origin, and default output has noindex and no sitemap. Literal IPs, local hostnames, credentials and non-root URLs are rejected; domain ownership/public reachability still must be checked by the deployer. Commercial examples remain noindex and excluded from the sitemap. CI uses the reserved .example domain in a private indexable fixture; only reports, not indexable HTML, are uploaded, then preview builds are restored. Do not deploy that fixture.

Mobile auto mode (viewport under 1024px) keeps the HTML and poster visible until scroll intent or explicit quality selection. Desktop auto retains poster-first idle enhancement. Reduced-motion and data-saving static modes avoid probing WebGL; existing manual controls remain. Verify real physical devices and post-interaction GPU performance separately.

The SEO shield uses Chromium DOMParser on both static builds to audit metadata, heading structure, image alternatives, structured data, preview/indexable policy, and robots/sitemap consistency. Lighthouse CI evaluates three mobile lab runs; median performance >=90, best practices >=95, LCP <=2500ms; worst accessibility >=95 and CLS <=0.1. Indexable fixture requires SEO 100 for every run; preview SEO remains a warning because of noindex. No guarantee of Google rankings or field CWV. Field targets at p75: LCP <=2.5s, INP <=200ms, CLS <=0.1; lab Lighthouse does not measure field INP. See https://developers.google.com/search/docs/appearance/core-web-vitals and https://googlechrome.github.io/lighthouse-ci/docs/configuration.html. No new npm dependencies, paid APIs or deployment.

Commands: npm run seo:check after both builds; npm run quality for preview; npm run quality:production only with isolated indexable build. Full workflow evidence in GitHub Actions. Preserve Step 10 license gates.
