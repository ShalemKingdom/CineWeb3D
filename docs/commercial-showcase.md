# Step 12 — Commercial Showcase / The Grounds
Private development concept in sandbox, not the official café website. Route: /examples/the-grounds/. The brief uses the brand name, provided slogan and Montellano/Puerto Plata location. No claims about live menu, prices, hours, reviews, bookings or exact address. No external resources, paid services or tracking. The wordmark is a typographic concept, not a verified official logo. Original vector illustrations and procedural geometry are included under the project's MIT license. No AI weights, photos or videos. Before public brand use obtain approval of copy, identity, assets and actual conversion destinations.
 
The Spanish landing page uses semantic HTML, responsive CSS, an original coffee poster, story/identity cards, location section, internal calls to action and a native FAQ. Existing Three.js engine supports a scoped canvas with coffee, saucer and beans, camera motion and scroll-driven rotation. Reuses Anime.js, Lenis, adaptive pixel budgets, demand-driven renderer, mobile intent and static fallback. IntersectionObserver suspends scoped rendering outside the viewport. No additional engine or animation loop. Demo route stays noindex even in production SEO fixtures. Build with npm ci && npm run build; preview using npm run preview and open /examples/the-grounds/. For browser evidence npm run test:e2e -- --grep Grounds; CI captures screenshots for static and interactive stage. Tests verify no-JS, noindex, mobile width, axe, canvas bounds, quality budget, scroll progress and fallback. Real device GPU, official brand assets, commercial functionality and public deployment remain outside step 12.
